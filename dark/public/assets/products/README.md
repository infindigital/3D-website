# Product package artwork

Supplied by the brand owner. Never generated. The committed files are the
owner's originals, web-sized with the studio-white background cut to alpha
so the pouches keep their real silhouette in the 3D stage and hero.

Current files, referenced from `src/config/products.ts`:

```
gobi-manchurian/front.webp   Front of the Gobi/Mushroom/Paneer 3 in 1 pack
gobi-manchurian/back.webp    Back of the same pack
three-in-one/front.webp      Front of the Chicken 65 / Fish / Gobi 3 in 1 pack
three-in-one/back.webp       Back of the same pack
```

The brand logo lives in `public/assets/brand/logo.png` (transparent).

To replace artwork, drop in a new file with the same name. Highest
resolution available is best, Next.js image optimization handles resizing.
The three-in-one files came from 360px listing images, so if higher
resolution print files exist, swapping them in will sharpen the 3D packs.
