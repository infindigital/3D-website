RS Chef'z — website files for Hostinger
=======================================

Built for: https://rschefz.com
Hosting:   Hostinger shared / Premium / Business (hPanel)


THE SHORT ANSWER
----------------

Upload  UPLOAD-TO-public_html.zip  into public_html and extract it there.

That one file is the whole website — the 3D world, the films, the
photography, the product pages and the .htaccess. Nothing else in this
download goes to the server, and nothing has to be deleted afterwards.

Everything else here runs on your own computer:

    UPLOAD-TO-public_html/      the same files, already unzipped, for FTP
    preview-WINDOWS.cmd         see the site locally, 3D and all
    preview-MAC-LINUX.command
    preview-server.mjs          (the launchers use these)
    preview-server.py
    HOW-TO-PREVIEW.txt


STEP BY STEP
------------

1. Log in to hPanel and open  Files -> File Manager.

2. Go into the  public_html  folder.

3. Delete anything already in there. A fresh Hostinger account usually
   has a default.php or an index.html placeholder. Leave public_html
   itself.

4. Upload  UPLOAD-TO-public_html.zip  into public_html.

5. Right-click it and choose Extract. Extract to public_html itself, not
   to a new folder.

6. Delete the ZIP once it has extracted.

7. When it is right, public_html directly contains:

       index.html
       404.html
       .htaccess
       robots.txt
       sitemap.xml
       favicon.ico
       og-image.jpg
       _next/
       assets/
       products/

   If instead you see  public_html/UPLOAD-TO-public_html/index.html ,
   move the contents up one level and delete the empty folder. The site
   will not work one level down.

8. In hPanel, point rschefz.com at this site and turn on the free SSL
   certificate (Security -> SSL). The site forces https, so the
   certificate has to exist or visitors get a warning.

9. Open https://rschefz.com and check three things:
       the 3D world moves as you scroll
       the film plays
       the two product links in the menu open


PREFER FTP?
-----------

Upload the CONTENTS of the  UPLOAD-TO-public_html  folder — the files and
folders inside it, not the folder itself — into public_html.

Make sure your FTP client is showing hidden files, or .htaccess will be
silently left behind. In FileZilla: Server -> Force showing hidden files.


WHY THE 3D WORLD NEEDS ALL OF IT
--------------------------------

The 3D world is not a single file. It needs both of these, whole:

    _next/      the three.js code, the scroll animation, the page
                transitions. The filenames contain a version hash, so
                nothing in here can be renamed or tidied up.
    assets/     the pack artwork, the photography and the three films.
                The artwork is not only shown on the page — it is painted
                onto the 3D packs as textures, so a missing file here
                means a blank pack in the 3D world.

If a page loads but looks plain, or the 3D never appears, something from
one of those two folders did not finish uploading. Re-upload that folder
rather than guessing.


IMPORTANT: THE .htaccess FILE
-----------------------------

.htaccess starts with a dot, so File Manager hides it by default. If the
product pages give "404 Not Found" after upload, that file did not make
it across.

In File Manager, use  Settings -> Show hidden files  and confirm
.htaccess is sitting in public_html next to index.html.

It is what makes /products/gobi-manchurian-masala work instead of
/products/gobi-manchurian-masala.html, and it also forces https, sends the
security headers and sets the caching rules. Without it the home page will
still load and the product links will not.


WWW OR NO WWW
-------------

Set up as: rschefz.com  (no www). www.rschefz.com redirects to it.

To prefer www.rschefz.com instead, open .htaccess and swap the two rules
under the comment "One host, not two" — the active one is commented as
such, and the www version is directly below it, commented out.


SEEING IT ON YOUR OWN COMPUTER FIRST
------------------------------------

Double-click  preview-WINDOWS.cmd  (or preview-MAC-LINUX.command). Your
browser opens the site by itself, with the 3D world, and it also prints an
address you can open on your phone and tablet over the same Wi-Fi.

Leave the black window open while you look; closing it stops the preview.
Full instructions, including the firewall and Wi-Fi gotchas, are in
HOW-TO-PREVIEW.txt.

Do not open index.html by double-clicking it — you get a plain page with
no design. That is not a fault; it is what a website looks like when it is
opened as a file instead of served. HOW-TO-PREVIEW.txt explains why, and
the separate offline download is the copy built for opening that way.


AFTER IT IS LIVE
----------------

1. Google Search Console -> add the property rschefz.com and verify it.
2. Submit  https://rschefz.com/sitemap.xml
3. Use URL Inspection on these three, and request indexing:
      https://rschefz.com/
      https://rschefz.com/products/gobi-manchurian-masala
      https://rschefz.com/products/three-in-one-masala


IF YOU CHANGE THE DOMAIN LATER
------------------------------

The domain is written into the page source (canonical tags, sitemap,
structured data), so these files only suit rschefz.com. For a different
domain the site has to be rebuilt:

    NEXT_PUBLIC_SITE_URL=https://newdomain.com npm run build:static

That regenerates the  out/  folder. Upload that instead.
