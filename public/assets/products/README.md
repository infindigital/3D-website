# Product package artwork

Supplied by the brand owner. Never generated.

Expected files, referenced from `src/config/products.ts`:

```
gobi-manchurian/front.png   Front of the Gobi/Mushroom/Paneer 3 in 1 pack
gobi-manchurian/back.png    Back of the same pack
three-in-one/front.png      Front of the Chicken 65 / Fish / Gobi 3 in 1 pack
three-in-one/back.png       Back of the same pack
```

The brand logo goes in `public/assets/brand/logo.png`.

PNG or WebP, highest resolution available. Next.js image optimization
handles resizing and format conversion at build time.
